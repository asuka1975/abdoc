# レビュー観点: フロントエンド

review エージェントが FE のファイルを含む PR で追加で確認する項目。人間のレビュアーも同じ表を使う。

| 観点 | 確認すること | 証拠 |
|---|---|---|
| 契約 | API 呼び出しが生成クライアント経由か。`generated/` を手で編集していないか | diff |
| 型 | `any` / `@ts-ignore` / `as unknown as` の追加が無いか | diff |
| アクセシビリティ | インタラクティブ要素にラベル、フォーカス順、コントラスト。`jsx-a11y` の警告 | lint 結果 |
| 状態 | サーバ状態と UI 状態の置き場が規約どおりか。無限再レンダリングの兆候（依存配列） | diff |
| 見た目 | スクリーンショットかトレースが PR 本文にあるか。デザインシステム外の色・サイズを直書きしていないか | PR 本文 |
| パフォーマンス | 画像サイズ、不要な `use client`、バンドルに大きな依存を足していないか | `pnpm build` の出力 |
| テスト | ユーザー操作単位のテスト（`@testing-library`）があるか。実装詳細（state 名）をテストしていないか | diff |
| i18n | 文言をハードコードしていないか（i18n を使っている場合） | diff |
