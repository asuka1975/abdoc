# レビュー観点: バックエンド（Go / Google Cloud）

review エージェントが BE のファイルを含む PR で追加で確認する項目。人間のレビュアーも同じ表を使う。

| 観点 | 確認すること | 証拠 |
|---|---|---|
| 契約 | 公開 API の変更が `contracts/` に反映され、後方互換か。破壊的なら移行手順が PR 本文にあるか | diff / PR 本文 |
| マイグレーション | 追加のみ（既存ファイル未編集）、down が書かれている、大きなテーブルのロックを伴う操作が無いか | `migrations/` の diff |
| 境界 | `domain` が外部パッケージを import していないか。DB アクセスが `store` 以外に無いか | diff |
| エラー | `%w` でラップ、ハンドラで適切な HTTP ステータス、内部エラーの詳細をレスポンスに出していないか | diff |
| 並行性 | `context` の伝播、goroutine のリーク、`sync` の誤用、タイムアウト未設定の外部呼び出し | diff |
| 入力検証 | リクエストの境界でパースと検証をしているか（parse, don't validate） | diff |
| 秘密情報・GCP | 資格情報のハードコード無し。Secret Manager / Workload Identity 経由。テストが本番資格情報を要求しない | diff / CI ログ |
| 可観測性 | 新しい外部呼び出し・ジョブに構造化ログとエラー計上があるか | diff |
| テスト | 受け入れ基準ごとのテスト。テーブル駆動。統合テストが必要な変更（SQL）に統合テストがあるか | `go test` の結果 |
| ロールバック | `risk:high` の場合、戻し方（フラグ、逆マイグレーション、前バージョンへの切り戻し）が PR 本文にあるか | PR 本文 |
